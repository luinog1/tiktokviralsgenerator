Roteiro por imagem

Cole o texto do viral.app distribuindo um bloco por foto, na ordem em que as imagens vão aparecer. Dentro de um campo, pule uma linha para mandar o texto seguinte para outra caixa da mesma imagem — sem linha em branco, a primeira linha vira o texto grande e o resto vira o apoio. A imagem 1 é a exceção: ela mostra só o hook, numa caixa só — o que você escrever ali sai como uma frase, sem texto de apoio e sem CTA. {% if casting_enabled %} Ela também recebe automaticamente uma foto com {{ 'mulher' if hook_subject == 'woman' else 'pessoa' }}; as demais recebem cenário (estética, viagem, comida). {% endif %}

Colar o roteiro inteiro e distribuir

Cole tudo de uma vez, escrevendo Imagem 1:, Imagem 2:… na frente de cada trecho — é o rótulo que diz em qual foto o texto entra, e ele não vai para a imagem. Dentro de um trecho, uma linha em branco manda o texto seguinte para a outra caixa daquela imagem. Sem rótulo, valem 2., --- e o intervalo de duas linhas em branco entre as imagens. Depois de distribuir, os campos abaixo continuam editáveis. O painel do goviral (Hook + Script N + Paragraph 1/2) é reconhecido como está, sem rótulo nenhum — ou use a tela Colar do painel, que já decide o nº de imagens pelo painel.
